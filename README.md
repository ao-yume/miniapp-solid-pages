# AoYume SolidJS — GitHub Pages mirror

Static build of the [miniapp-solid](https://github.com/ao-yume/miniapp-solid) port (private source), hosted at **https://ao-yume.github.io/miniapp-solid-pages/**.

Production host is the Cloudflare Workers path (ao-mini.sudden-epiphany2.workers.dev/miniapp/) — see docs/DEPLOYMENT.md in the source repo. This Pages site is the public demo mirror, rebuilt with `vite build --base=/miniapp-solid-pages/`.

Open a TMA-less browser preview: [https://ao-yume.github.io/miniapp-solid-pages/](https://ao-yume.github.io/miniapp-solid-pages/) (auth falls back to the dev Login without Telegram initData).
